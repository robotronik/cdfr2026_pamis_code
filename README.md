# CODE PAMIS CDFR 2026 
Ce repo est le code des Petits Actionneurs Mobiles Indépendants de la coupe de france de robotique de l'édition 2026 'Winter is comming' 

Le robot tourne sur un esp32 s3, le détail exact ce trouve sur le repo https://github.com/robotronik/cdfr2026_pamis avec la PCB et la CAO

Utilisation du rust pour que le code reste entre les personnes queers qu club
